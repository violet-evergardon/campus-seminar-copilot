# 检索与排序

默认公式严格为：

`final_score = 0.45 × semantic_score + 0.30 × keyword_score + 0.25 × time_score`

随后仅以小权重加入用户兴趣和质量分，并保留所有分量。关键词字段权重为标题 0.50、标签 0.23、摘要 0.19、主讲人 0.08。无 embedding 时，语义分使用规范化中英文 token/中文二元组余弦式重叠；时间分对过去活动为 0，对未来活动采用 `1 / (1 + days / 7)`。

用户结果仅包含 `published`、质量分不低于 0.45 且未过期的活动。解释理由由命中阈值的确定性规则生成。问答先解析“今天/明天/本周/下周/本月”，最多两轮检索与去时间词重写；无结果明确说明，并记入坏案例。

可选 Milvus 2.5 方案使用 BGE 中文稠密向量、BM25 稀疏向量、HNSW 与 RRF。连接是惰性的，不配置 `MILVUS_URI` 时完全不导入或连接 Milvus；同步只增量 upsert，不删除 Collection。
