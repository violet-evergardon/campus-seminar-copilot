# 数据模型

- `Event`：完整活动字段、状态、质量/置信度、指纹、解析证据和索引时间。
- `User`：用户名、角色和兴趣标签。
- `Favorite`：用户与活动唯一关联。
- `Feedback`：帮助性、错误、缺失等反馈；负反馈同步生成坏案例。
- `BadCase`：查询、错误/期望结果、错误类型和处理状态。
- `CrawlSource`：站点、白名单入口、适配器、游标与最近成功时间。
- `CrawlRun`：每站运行模式、发现/新增/重复数和失败原因。
- `AdminReview`：审核动作、备注和字段快照。

`Event.status` 为 `draft / published / rejected / expired`。缺失主讲人、时间、地点或来源保持空值，前端显示“待补充”。跨来源去重键由规范化标题、活动日期和主讲人组成；重复来源进入解析证据，不覆盖已审核事实。
